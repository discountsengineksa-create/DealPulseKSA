## طريقة التسليم (تجعل التنزيل غير ضائع)

1. **مجلّد لكل دورة** داخل `Downloads\البيت\سيو\` — يُفضَّل اسم لاتيني (المسار العربي
   ينكسر عبر Git Bash ويُعالَج بنسخة PowerShell، فالاسم اللاتيني يوفّر خطوة).
2. كل درس: افتحه في المشغّل ثم `Ctrl+S` → **Web Page, Complete**.
   ⚠️ الصفحة الظاهرة ليست الدرس — النصّ في `_files/launcher_data/index_data/.../index_*.htm`.
3. **مخرَجي لكل دورة:** خلاصة مكثّفة + **ما يتغيّر عندنا فعلاً** (إعداد، كود، أو قرار)،
   تُضاف إلى `ga4_curriculum.md` أو ملف الحملات — لا تلخيص معلّق في الهواء.
