**القياس الحيّ (GSC ٢٨ يوماً، سُحب ٢٠٢٦-٠٩-٠٢ عبر Windsor searchconsole):** عنقود
الإدارة المدرسية/نماذج المعلمين ينتج **~١١٠+ نقرة/٢٨ يوماً** — أكثر من `/calendar`
(١٢٩) إذا جُمعت صفحاته — وبمعدّل نقر ١٠–٢٠٪: `duty-supervision-schedule-saudi`
١٩ نقرة/١٣٥ ظهور (14%)، `school-safety-plan-saudi` ١٥/١٣٧ (11%)،
`curriculum-distribution-plan-guide-saudi` ١٥/٣٧٣، `student-activities-plan-guide-saudi`
١٠/١١٣ (م ١٢٫٢). المراكز ٤–١٥. `marketing_baseline` يسمّيه «اكتشاف غير مخطَّط».

**لماذا يفوز وبقيّة العناقيد لا:**
- طويل ذيل منخفض المنافسة ⇒ DA=1 يرتّبه صفحة ١ (بخلاف «كود خصم نمشي» م ٤٥+ = سقف سلطة)
- نيّة معلوماتية ⇒ النقرة **لنا** لا للمتجر (صفحات المتاجر: نمشي ٢٣٣٤ ظهور ← ٥ نقرات)
- منافسو الكوبونات (الموفّر/الكوبون/بيكودي…) **صفر محتوى هنا** — ساحة فارغة تماماً
- الطلب موسوم بالسنة الهجرية («توزيع المنهج ١٤٤٨»، «خطة النشاط الطلابي ١٤٤٨»)
  ومتجدّد كل عام. اليوم = ٢٠ ربيع الأول ١٤٤٨ (محسوب)، والعام الدراسي ١٤٤٨ جارٍ.

**ما نُفِّذ ٢٠٢٦-٠٩-٠٢ (web `842f669`):** صفحة هَب **`/school-templates`** — ٣٤ دليلاً
في ٦ مجموعات (الخطط والتوزيعات · السجلات · نماذج المعلمين حسب التخصص · شؤون الطلاب ·
ملف المعلم المهني · الإذاعة والمناسبات والمناوبة)، Schema
(CollectionPage + ItemList + FAQPage + Breadcrumb + `datedWebPageSchema`)، ٥ أسئلة
بصيغ GSC الفعلية. الأدلّة تُفلتَر حيّاً بـ`getPostBySlug` (رابط مقالٍ أُعيدت تسميته
يسقط بهدوء لا 404 — نفس درس commit `93e8041` «العقدة الثالثة لدرس اليوم ١٩»).
وُصلت: `STATIC_PAGES` (سايت‌ماب) + رابط سِتوايد في `FooterSeoLinks` (قسم المواسم) +
بانر في `/back-to-school`. **التحقّق:** `next build` كامل `EXIT=0` (١٩٩٢/١٩٩٢)؛ الـHTML
المُصيَّر يحمل CollectionPage و FAQPage بـ٥ عقد Question و٣٤ رابط `/blog` فريداً.

**كان العنقود بلا صفحة أمّ** — ٣٤ مقالاً يترتّب كلٌّ وحده بلا هَب يجمع النيّة أو
يمرّر السلطة.

**الخطوات التالية (لم تُنفَّذ):**
1. **ربط عكسي** — رابط `/school-templates` في «روابط ذات صلة» بكل مقال من الـ٣٤
   (سكربت idempotent، يلمس `blog.ts` ⇒ `next build` كامل إلزامي —
   [[web_repo_verification_recipes]] §الخطر).
2. **٢–٣ مقالات شقيقة** لفجوات مقيسة: رأس «نماذج المعلمين»، «توزيع المنهج» بصيغه
   الموسومة، «الفصل الدراسي الثاني ١٤٤٨».
3. دفع `/school-templates` للفهرسة (IndexNow + Google) بعد اكتمال بناء Vercel.

يخدم [[seo_page_portfolio_verdict]] (التجميع = النمط الوحيد المُثبت) و
[[blog_internal_link_deorphan]] و [[seasonal_school_traffic_bridge]] و
[[marketing_baseline_and_strategy]] (المحرّك الواحد الكاسب — يتّسع الآن لمحرّكين:
