# أخطر ٥ عالمياً على Maqalat
1. **موضوع + سطور** — احتكار الذيل العام العربي.
2. **المرسال** — trivia+أبراج+أحلام (ترافيك ضخم مستدام).
3. **سيدتي** — النساء والمجتمع الخليجي.
4. **الطبي** — YMYL طبي معتمد.
5. **الجزيرة نت** — الإخباري/السياسي العربي عالمياً.

# ٥ فجوات استراتيجية لا يُغلقها المنافسون قريباً
1. **E-E-A-T 2026 حقيقي** — Person Schema+كاتب موثّق+LinkedIn+مصادر NIH/Harvard/Mayo مربوطة inline.
2. **لا AI-slop** — بعد HCU 2024-2025 صار AI-typical خصماً؛ الصوت البشري = ميزة.
3. **أدلة خدمات حكومية خليجية بالعربية** بجودة تحريرية (تجديد إقامة/رخصة/تأشيرات لكل ٦ دول GCC).
4. **مقارنات جامعات خليجية بالعربية** (رسوم+تخصصات+QS+شروط قبول).
5. **تقاويم Evergreen محدّثة سنوياً بتاريخ ظاهر**.

# ٣ نماذج دخل مقترحة (بالترتيب الأمثل)
1. **AdSense كأساس** (كما مخطط) — لكن مع تنويع فوري لتجنّب مصير HowStuffWorks.
2. **أفلييت انتقائي** لصفحات مقارنات (كتب/دورات/أدوات) — بدون كسر YMYL.
3. **مقال مدفوع/تقرير Deep** بسعر 5-20 ريال على نموذج note.com — لجمهور مثقّف عربي لم يجرّبه أحد بجدية.
