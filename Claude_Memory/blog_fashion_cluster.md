## الزي المدرسي بالاسم — الميزة الأبرز (طلب المالك صراحة)

المتجر يبيع زياً مطابقاً لأربع مدارس محدّدة بالاسم + الحكومي:

| المدرسة | التغطية |
|---|---|
| نور الإسلام | أولاد/بنات، رياض الأطفال–١٢، تربية بدنية، بدلة رياضية |
| الفيصلية | نفس البنية |
| جرين هيلز العالمية (GHIS) | نفس البنية |
| المنارات | نفس البنية |
| الحكومي | رياض أطفال/ابتدائي/متوسط/ثانوي + تربية بدنية |

**حائط سلامة معلوماتية مطبَّق في كل مقال مدرسة:** «راجعي تعميم المدرسة الرسمي قبل الشراء — كتالوج المتجر مرجع تسوّق لا بديل عن التعميم». لا ادّعاء مطابقة ١٠٠٪ لمتطلّبات أي مدرسة تحديداً — صدق استباقي بدل اعتذار لاحق.

**فرصة تكامل مستقبلية (لم تُنفَّذ):** [[school_admin_cluster_engine]] هو «المحرّك الأول» للموقع (34 مقال قوالب معلّمين، ~110+ نقرة/28ي) لكن جمهوره (معلّمون/إداريون) مختلف عن جمهور شراء الزي (أولياء أمور) — لم أُجبر رابطاً بينهما تجنّباً لـ«توسيع نطاق» بلا صلة فعلية.
