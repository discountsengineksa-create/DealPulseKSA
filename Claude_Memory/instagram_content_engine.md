إنستقرام **@dealpulseksa** («كوبونات خصم نبض الصفقات») كان 45 منشور / **5 متابعين** — لأن الفيد ~100% منشورات كوبونات تلقائية (ترويج بحت لا يكبّر متابعين).

**بنينا (يونيو 2026):**
- `api/social/content_reels.py` — مولّد كاروسيلات محتوى **فاخر Dark Luxe** (1080×1350): خلفية زمردية-فحمية متدرّجة + لوقو + حاويات بظل + خط Noto (Cairo-Bold بالمستودع **لاتيني فقط** لا يدعم العربي). يعيد استخدام محرّك `ig_slides`. فيه `render_content_slides(concept)` + `render_image_slide(image,text,kicker)` + قائمة `CONCEPTS` (20 مفهوم نمو بلا رموز).
- تبويب **«🎬 ريلز المحتوى»** في dashboard.py (صفحة «استوديو المحتوى»): 3 أوضاع — مفاهيم جاهزة / اكتب مفهومك / صورة+نص. تنزيل ZIP أو شريحة.
- `api/social/template.py` — نوّعنا hook كابشن إنستقرام (`_pick` ثابت لكل متجر، متنوّع عبر الفيد).
- أضفنا إنستقرام لـsameAs (lib/seo/constants.ts بريبو الويب).

**موجود مسبقاً:** نظام نشر إنستقرام كامل (Meta Graph API + `InstagramPoster` + `reels_video` = صورة→MP4 ثابت عبر Cloudinary).

**✅ insights صارت مقروءة (2026-07-15):** عبر Windsor.ai MCP، connector `instagram`، account id `17841444145819859`. الجداول: `media_insights` (لكل منشور: media_reach/engagement/follows/saved/shares) و`user_insights_day_total_value` (reach/views/total_interactions يومي) و`user_info` (followers_count لقطة اليوم). ملاحظة: `follower_count_1d` (متابعون جدد يومياً) غير متاح للحسابات <100 متابع (يرجع null). سحب كل الميديا بمدى تواريخ واسع يتجاوز حد الـtokens → احفظ للملف وحلّل بـPython (لا jq — غير مثبّت). لا حاجة لتوكن Meta السرّي.

**🔴 تشخيص «ليش الحساب ميت» (2026-07-15، من الـinsights الحقيقية):** ٥٦ منشور / **٥ متابعين** / يتابع ١٥١. **صفر متابع جديد جاء من أي منشور** (`media_follows=0` عبر الـ٥٦). إجمالي التفاعل مدى الحياة = ١١ (١٠ لايك + ١ تعليق)، **صفر حفظ، صفر مشاركة**. السبب الجذري: الفيد (٥٠ بوستر كوبون تلقائي) متوسط وصوله **1.1** (١٣ منشور وصولها صفر) — إنستقرام 2026 لا يوزّع الصور الثابتة لغرباء. **الريلز (٦) هي الوحيدة التي توصل: متوسط 44.7 أقصى 123** (٤٠× الفيد) → مو shadow-ban، الصيغة غلط. الوتيرة انهارت يونيو ٥١ → يوليو ٥. الإصلاح المتّفق عليه اتجاهاً: أوقف بثّ بوسترات الفيد (كل وصول-1.1 يخفّض تقييم الحساب) → أتمتة Reels-only + ≥٦٥٪ محتوى قيمة (حفظ/مشاركة/سبب متابعة) + نظّف نسبة المتابعة المعكوسة + استمرارية يومية. السقف الصادق: بـ٥ متابعين النمو العضوي بطيء مهما تحسّن المحتوى — الرافعة = دفع أول ٥٠٠-١٠٠٠ متابع من تيليجرام/الموقع المملوكين.

**🔎 تصحيح + اكتشاف (2026-07-15):** الكابشنات التلقائية **نظيفة** (`build_batch_caption` في reels_batch.py و`_build_text_instagram` في template.py — راجعتهما). الرموز المكسورة (`⁨\t#⁨\t`) ظهرت فقط في ريلَي 12+15 يوليو وهي **منشورة يدوياً** (النص غير موجود بالريبو) — مصدرها أداة النشر اليدوي لا كودنا. **الأهم:** ريلات الوصول 100+ (106، 123) كلها **يدوية**، بينما الأتمتة تنتج فقط: كاروسيل فيد (وصول ~1) + ريل باتش «6 كوبونات» (وصول 8-20). أي محتواك اليدوي البسيط يتفوّق على الأتمتة 5-10×.

**✅ نُفّذ (2026-07-15) — إيقاف كاروسيل الفيد التلقائي:** `api/social/dispatcher.py:_run_instagram_extended` صار **Reels-only** ببوّابة بيئة `IG_AUTO_FEED_ENABLED` (افتراضي `0`=موقوف). عند الإيقاف يُتخطّى كل مسار الفيد (لا log، لا شرائح، لا نشر) وتُغذّى قائمة الريل فقط → كل 6 بثّات = ريل. للإرجاع: `IG_AUTO_FEED_ENABLED=1` في بيئة Railway (بلا تعديل كود). العلّة الجذرية: بوستر بوصول 1.1 يكبح تقييم توزيع الحساب.
