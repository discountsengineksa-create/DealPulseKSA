مدوّنة الويب (lib/blog.ts) فيها **292 مقال، منها 150 مقال AliExpress قطع/إكسسوارات سيارات** أنشأها المستخدم سابقاً على جهازه الثاني («يوم كان كلود غبي»). هي سبب توسّع الـsitemap إلى ~402 وأغلب الـ**244 «مكتشفة لم تُفهرس»** في GSC (انظر [[seo_indexation_status]]).

**العطل الجذري (اكتُشف 2026-07-03):** الـ150 مقال كانت تُعرض **جدار نص واحد مكسور** منذ إنشائها — أجسامها مخزّنة بـ`\n` حرفية (backslash-n) بدل أسطر، والعارض markdown-lite ما يدعم الجداول/`>`. **الإصلاح (web commit b3db0ce):** [BlogPostContent.tsx] → `renderBody` صار (١) يطبّع `\n` الحرفية لأسطر فعلية، (٢) يدعم الجداول `| .. |` والاقتباسات `>`، (٣) يجزّئ الكتل المختلطة نص+جدول. **الآن كلها تُعرض مُهيكلة.** ⚠️ عيب التوليد الأصلي، مو ريجريشن مني.

**الأسعار:** كانت أرقام/نطاقات **+ تقييمات ⭐ مفبركة**؛ حُذفت بطلب المالك (web commit d941883، 2026-06-28) فبقيت **أسعار فاضية + جُمل مبتورة** (~195 «السعر:» + 161 خلية جدول فارغة). **القرار: مستويات وصفية** (اقتصادي/متوسط/محترف) بلا أرقام — صفر فبركة، لا تتقادم. **لا تسترجع نسخة ما قبل d941883 بالجملة** (تُرجع الـ⭐ المفبركة).

**القرار (2026-07-03): المالك اختار «نصلح الكل» لا التنقية — ونُفّذ.** (أوصيتُ بالتنقية+noindex لكنه أراد إصلاح 150 كلها.) **الطريقة المنفّذة (web commit 0fc8442، بلا فبركة):** سكربت Python يطابق كل سطر جسم من diff الأصلي d941883 (فيه الأسعار الحقيقية)، يحوّل الأسعار لمستويات وصفية **مربوطة بأرقامها الفعلية** (اقتصادية<200 / متوسطة<600 / متقدّمة<1500 / احترافية≥1500 ريال)، بنحو صحيح (بأسعار=نكرة، الفئة=معرّفة)، ويزيل التقييمات ⭐ المفبركة. 1103 استبدال، البناء سليم، صفر تنوين متبقٍّ. **درس: أي تحويل نصّي عربي آلي = طبّق `re.sub` على السطر المُستبدَل فقط لا على كل الملف (سحق مسافات الكود)؛ واحذر لواحق التنوين `[\wً-ْ]`.** بقايا مقبولة: ~7 «ريال» عامة + ~20 خلية جدول فاضية. السكربت في scratchpad.

**أصل /calendar (2026-07-03):** بُنيت صفحة «تقويم تخفيضات السعودية» كأصل باكلينك قابل للاستشهاد (انظر [[seo_indexation_status]]). Ahrefs رصدها **Orphan** (بلا روابط داخلية) → أُصلح (web commit ccee389): أُضيفت لفوتر «استكشف» سايت-وايد + رابط سياقي من الدليل المحوري. **درس: أي صفحة جديدة لازم روابط داخلية داخلة، لا الـsitemap وحده.**

**تحقّق دوري:** بعد أي دفعة كبيرة → زحف Ahrefs جديد + GSC «التحقق من الإصلاح» لتأكيد نزول «مكتشفة لم تُفهرس».

**404 «ذا ديل» — السبب الحقيقي (2026-07-03، web commit 4fb45c7):** مو كاش/قاعدة. btrim صلّح slug القاعدة (`/store/ذا ديل`=200)، **لكن رابطين في lib/blog.ts كانا يحملان الشكل القديم `/store/ذا ديل%20`** (مسافة زائدة مطبوعة → 404). حُذفت المسافة. **درس: بعد btrim على حقل يدخل URL، افحص الروابط الثابتة (blog/hardcoded) مو القاعدة فقط.**

**🧵 عنقود الأزياء بدأ (2026-07-03، بقرار المالك رغم توصيتي بالباكلينك أولاً):** التحوّل من سيارات→ملابس (طلب سعودي أعلى). الموجود أصلاً: أزياء نسائية(هَب)/عبايات/أحذية/رجالي/أطفال/مقاسات/لانجري/رياضي + **عنقود مشدّات عميق ×8**. الفجوات المستهدفة: فساتين مناسبات/محجبات/نوم/شتوي/بلوزات/سباحة — **الستة كلها أُنجزت** (web 3409215 + a05dc2b): occasion-dresses، modest-hijab-fashion، womens-sleepwear-pajamas، womens-winter-coats، womens-blouses-shirts، womens-swimwear-burkini. كل مقال 6-9 أقسام + جدول + تسعير وصفي + إفصاح + 9-13 رابط داخلي، ومربوط من الهَب. **القاعدة: منتقاة على الفجوات + ربط داخلي قوي (هَب womens-fashion-guide + أخوات + متجر + /calendar) لعلاج «رابط داخلي وحيد ×36».** المقال الجديد body=backtick (أسطر حقيقية، لا `\n` حرفية).

**📚 توسّع أزياء+أحذية ضخم (2026-07-04، بقرار المالك «3 مقالات لكل قسم فرعي»):** أنجزتُ **~50 مقال** بنفس المستوى (محتوى خبير + جدول + تسعير وصفي + FAQ + 9-13 رابط داخلي + مربوطة من الهَب): **ملابس نسائية 8 أقسام×3 (17)** + **ملابس رجالية 8 أقسام×3 (24، هَب mens-essentials)** + **أحذية 3 أقسام×3 (9، هَب footwear)** + **الجمال والعناية 7 أقسام×3 (21، هَب beauty-skincare-guide)** + **المجوهرات والإكسسوارات 5 أقسام×3 (15، هَب jewelry-buying-guide)** = **86 مقال**. blog.ts ≈431 مقال. **صدق المجوهرات:** أُصيغت كإكسسوار/ستانلس/مطليّ لا ذهب/ألماس حقيقي (الذهب الحقيقي له gold-buying-guide). **⚠️ في «الجمال» استُثنيت أقسام غير لائقة (جنسية/BDSM) + طبية YMYL (أدوية OTC) + المكرّر (عطور/عود ×13، مكمّلات/فيتامينات)؛ الجمال محتوى تجميلي إرشادي بإخلاء طبي بكل مقال.** الأسلوب: slug `aliexpress-<...>-saudi-arabia`، body backtick، سكربتات Python بالـscratchpad (men1-4/shoe1-2/add_batch*). **تنسيق جهازين:** المالك يقسم الأقسام (هو أثاث/ألعاب/... وأنا الملابس/الأحذية) → صفر تعارض، pull-first قبل كل push. **تحذير استراتيجي قائم:** هذا يخالف توصيتي (الفهرسة محبوسة بالباكلينك لا بعدد الصفحات)؛ نُفّذ بإصرار المالك.

**🐛 باگ عرض الجداول (أُصلح web 3409215):** `isSep` في [BlogPostContent.tsx] كان `test(row.replace(/[^|:\-\s]/g,''))` → يجرّد النص فيصنّف **كل صفوف الجدول كفواصل** ويبلع محتواها (فقدان بيانات صامت في كل مقالات AliExpress ذات الجداول). الإصلاح: `row.includes('-') && /^[\s|:\-]+$/.test(row.trim())` (يطابق سطر الفاصل `|---|` فقط). استعاد جداول المقال الجديد + carplay + غيرها.
