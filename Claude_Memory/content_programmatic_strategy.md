تعبئة الموقع بمحتوى عربي حقيقي قبل الزحف القادم (جلسة 2026-06-25):

**القرار الإلزامي — لا تبني /en (ثنائية AR/EN):** الجمهور والطلب عربي، والدليل من الكود نفسه: صفحات /c الإنجليزية **noindex** (`index: page.lang !== 'en'` في app/c/[slug]) ومستبعدة من sitemap.ts بتعليق صريح «طلبها ضعيف». نشر /en = ~130 صفحة إنجليزية تنافس طلباً ضعيفاً على دومين لا يُفهرس عربيّه أصلاً = تبديد + يناقض قرارهم. **عمّق العربي بدل /en.** (راجعها لو تغيّر وضع السلطة/الطلب مستقبلاً.)

**القاعدة:** كمية الصفحات بلا قيمة فريدة = نفس أزمة الفهرسة الحالية × N (راجع [[seo_indexation_status]]). كل صفحة لازم محتوى/داتا فريدة فعلية. «1000 صفحة رقيقة» مرفوضة (تضر السمعة).

**ما أُنجز:**
- `lib/seo/category-content.ts` → `getCategoryContent(tag, count)`: مقدمة تحريرية + FAQ + نصائح لكل قسم (منتقى لأعلى ~28 قسماً + مولّد قوي للباقي، يشمل صحة/مكمّلات/فيتامينات لـ iHerb). تُستهلك في app/category/[slug] (مقدمة + نبذ من store_bio + نصائح + FAQPage schema).
- `components/FooterSeoLinks.tsx`: هَب روابط كل الأقسام سايت-وايد (يقلّل اليُتم).
- **19 مقال عربي** أُضيفت لـ `lib/blog.ts` (إجمالي 37): عطور/مكياج/جوالات/سيارات/قهوة/وايت فرايداي/عسل/عود/مجوهرات/أطفال/منزل/رمضان/الوطني/أحذية/ساعات/رياضة/هدايا/مواقع عالمية/مستلزمات رجالية. كل مقال دليل شراء حقيقي + **روابط داخلية مُرمَّزة لمتاجر فعلية** (من كتالوج 42 متجر) + أقسام + /deals + /trending.

**نمط إضافة المقال:** كائن BlogPost في `lib/blog.ts` (body = template literal markdown-lite، روابط `[نص](/store/ENCODED)` بترميز quote). ⚠️ بيئة البناء المحلية تخرج من الذاكرة (OOM) حتى على tsc لهذا الحجم — تحقّق يدوياً (backticks متوازنة + صفر `${` + slugs موجودة) واعتمد على Vercel.

**عنقود الإلكترونيات والسيارات (2026-06-26، web commit ae46106، +8 مقالات → إجمالي 47):** phone-accessories / refrigerator / washing-machine / tv-buying / iphone-buying / android-phones / engine-oil / car-detailing (كلها `-guide-saudi-arabia`). كل دليل محتوى مجال فريد (لا قالب) + ربط داخلي للعنقود (حُدّث المقال المحوري + smartphone-guide + car-care-parts-guide).

**نتيجة مخزون مهمة:** متاجر الإلكترونيات في الكتالوج كلها **إكسسوارات** (رايات/ماس/خيارات/متجر اكسسوارات جوالي = شواحن/سماعات/كفرات/ملحقات Apple) — **لا متجر متخصّص بالأجهزة الكبيرة**؛ منفذ الثلاجات/الغسالات/التلفزيونات الوحيد = **نون** (+علي بابا جملة). فأدلّة الأجهزة الكبيرة محتوى معلوماتي يبني سلطة الموضوع مربوط بنون، لا عنقود أفلييت عميق. السيارات: كاركستريم/وولفيكس (قطع+زيوت AMSOIL)/سويتر (تلميع). ⚠️ **علي اكسبرس `seo_enabled=false` → محظور من محتوى SEO** (لا يُربط).

**دفعة الأزياء/الذهب/عمق نون (2026-06-26، web commit 27be054، +7 → إجمالي 54):** womens-fashion / online-clothing-size / gold-buying / laptop-buying / kitchen-appliances / gaming / car-tires-battery. صحّح المالك تقديري للمخزون: العمق حقيقي.

**خريطة المخزون الكاملة (مهمة — استُعلمت كلها):** 42 متجراً، **كلها الآن `seo_enabled=true`+نشط**. ⚠️ **علي اكسبرس (id=9) فُعّل seo_enabled=true يدوياً 2026-06-26 بطلب المالك صراحةً** (كان المستبعد الوحيد؛ كوبونه «استخد الرابط للخصم» مو كود فعلي). نُشر له دليل blog (aliexpress-shopping-guide-saudi-arabia، commit 340b4fa) → إجمالي 55 مقالاً. تنبيه: تفعيله قد يجعل auto-pipeline يولّد له صفحة /c/ — راقب الجودة. أزياء مدعومة بقوة: نمشي(كاش10%)/ستايلي(14%، وسوم ضخمة)/H&M/فوغا كلوسيت/جولينا/المخملية+بنت الشيخ+ديزاج+عذية+ماي سكاريف(عبايات). ذهب: بيلاس/علي الصقعبي/لاكجري. نون = العالم الوحيد للأجهزة الكبيرة + لابتوب/ألعاب/مطبخ. علي بابا(جملة) مفعّل. ⚠️ راوت /store يطابق store_id **حرفياً بعد decode** → أي مسافة لاحقة تكسر الرابط (تجنّب «ذا ديل » trailing space)؛ تحقّق exact-match قبل الترميز (quote safe='').

**عنقود العود المعرفي (2026-06-26، commits 1071a63 + 4a24acd، +3 → إجمالي 58):** oud-types / real-vs-fake-oud / oud-extraction. هذا **النموذج المتّفق عليه** للتوسّع: عمق معرفي ثري بمستوى الخبير (وصف حسّي/مصطلحات/حرفة، نبرة متخصّص بلا مبالغة) + ربط داخلي بين الثلاثة + هَب من oud-bukhoor-guide + FAQ schema، مربوط بـعود رويال (عود طبيعي موثّق تحقّقت منه بالـWebFetch). المالك يريد «القارئ يحس إني متخصّص ٥٠ سنة» = نوصلها بالعمق لا بتوقيع مؤهلات مفبرك (E-E-A-T/أمانة). **عنقود واحد عميق ينتج ~8-11 صفحة متمايزة فعلاً** (تبخير/استخدام الدهن/المعمول/التخزين/المخلّط/الأسعار/مقارنات مصادر) — هذا «الكثير القوي» الصح مقابل آلاف الصفحات الرقيقة.

**قيد تحقّق المخزون (2026-06-26):** معظم المتاجر Salla/Zid/تطبيقات (SPA) → WebFetch **ما يقرأ كتالوجها** (نجح: فوغا كلوسيت + المخملية=عبايات مخمل/كلاسيك/تفصيل + عود رويال=عود طبيعي؛ فشل: ستايلي، أغلب سلة). فالمحتوى المربوط بكتالوج كل متجر تلقائياً غير ممكن بالأدوات الحالية → نعتمد محتوى تعليمي دقيق (مستوى السوق) + ربط للمتاجر؛ للمحتوى المربوط بالكتالوج: المالك يعطي الأصناف أو feed أفلييت.

**عنقودا مترو البرازيل + سويتر (من جهاز المالك الثاني، 2026-06-26):** مترو=مشدات برازيلية (10) + سويتر=غسيل/تلميع سيارات متنقّل (10). دمجتُها (rebase حلّ تعارض blog.ts الكبير): ربط بالمحوري الرئيسي + كتلة روابط لكل محوري + ربط متبادل مع عنقودَي السيارات/الأزياء + صفحتان مؤسستان على الموقعين (WebFetch): shapewear-compression-levels-guide + mobile-car-wash-water-saving-saudi (USP سويتر 7ل مقابل 120). **الإجمالي 90 مقالاً** (commit 4f5b11a). الـ20 كانت شبه يتيمة (بلا category/deals) فربطتها.

**سير العمل بجهازين:** المالك ينشر blog.ts من جهازه الثاني → افحص divergence قبل الشغل؛ تعارض blog.ts متوقّع (إضافات متوازية للمصفوفة) → rebase + احتفظ بالطرفين + فحص (scratchpad/check_blog.js: عدد/تكرار/روابط مكسورة). [[git-sync-workflow]].
