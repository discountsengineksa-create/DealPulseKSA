## المرجعية

تركيب من: SQRG (Google Search Quality Rater Guidelines سبتمبر 2025) + AdSense 2026 policies + AI-detection 2026 patterns + Voice Bible (نبض الصفقات) + Content Guardrails + مقالاتنا العشر الحالية. **آخر تحديث: 2026-09-02**.

## 1) قواعد E-E-A-T 2026 (اقرأها أولاً)

Google في ٢٠٢٦ يقيس أربعة أشياء بترتيب صارم — **Trust هو الأساس**:
- **Experience** — تجربة أولى بشخصنا أو بالمصدر (لا نقل قوقل)
- **Expertise** — مصطلح دقيق + عمق تقني
- **Authoritativeness** — نُعرف بالموضوع، مصادرنا معروفة
- **Trust** — دقة + شفافية + كاتب موثّق + سياسة تحرير

**YMYL توسّع في سبتمبر ٢٠٢٥** ليشمل: صحة، مال، قانون، **حكومة/مدنيات/انتخابات**، سلامة. مقالاتنا: التحصيلي (تعليم) + الرواتب (مال) + الزكاة (دين+مال) + الحمل/الدورة/BMI (صحة) = **٧ من ١٠ مقالات YMYL**. المعيار الأعلى.

**تحديث فبراير ١، ٢٠٢٦**: Google أضاف قسم Authors صريح في Search Central — التوقيع بكاتب معروف ذي مؤهّلات موثّقة = **إشارة جودة مباشرة**، لا تحسين اختياري.

## 2) قواعد تجنّب AI-Detection

Google لا يعاقب على "AI كتبها" بل على **أنماط AI الرخيصة**. المطلوب:

| الفخّ | الحدّ الأقصى المسموح | نموذجنا الحالي |
|---|---|---|
| **صيغة المبني للمجهول** | 5-12% (بشري) — 20-30%=AI مؤكّد | لم يُقَس بعد ✗ |
| **جُمَل بنفس البدء** ("يُعدّ من أهم"، "من الأشياء التي") | صفر — نوّع بدايات الجمل | ✗ يوجد بعض |
| **قوائم نقطية مفرطة** | لا تتجاوز ٤ قوائم لكل ١٠٠٠ كلمة | ⚠️ مقالاتنا فيها إفراط |
| **ملخّصات "خلاصة/تلخيصاً"** | صفر — الخلاصة تُقرأ من المحتوى | ⚠️ توجد في الرواتب/الزكاة |
| **إطناب "من المهم أن نذكر"** | صفر | ✗ بعض |

**إشارات "بشري" إيجابية (زوّدها):**
- **رأي بقناعة**: "لا تعتمد أم القرى إن كنت خارج السعودية — استخدم تقويم Umm al-Qura API الصينية"
- **خلاف مع الشائع**: "خلافاً لما يشاع في مواقع الفتوى، الذهب المستعمَل لا زكاة عليه عند الجمهور"
- **جملة أنا/نحن حقيقية بتفاصيل**: "راجعنا موقع أم القرى في ٢ سبتمبر ٢٠٢٦ فوجدنا…"
- **مصطلح إقليمي مسموح**: "نظام حماية الأجور"، "مفاضلة"، "الدفعة"، "بدل الترقّي"
- **عدم دقّة معلَنة**: "لم نجد رقماً رسمياً محدَّثاً — سنحدّث حين يصدر"
- **em-dash + جملة قاطعة**: "الفكرة أبسط ممّا يُقال — الحول يبدأ من يوم بلوغ النصاب. نقطة."

## 3) قواعد AdSense (لا حظر)

- ❌ **يُحظر**: محتوى AI طلقة واحدة بلا مراجعة + محتوى رقيق (thin) + قابل للنسخ من موقع آخر
- ✅ **يُقبل**: محتوى AI بمراجعة بشرية + قيمة أصلية + كاتب معروف
- **العتبة**: ١٥-٢٠ مقال + About + Privacy + Contact + Editorial Policy (لدينا)
- **رافعة رفض شائعة**: "Low Value Content" — سبب فوز خصوم عندنا: مقال طويل بلا زاوية أصلية + توقيع "فريق X" مجهول

## 4) البنية الإلزامية لكل مقال Maqalat

```
Frontmatter:
- title (55-60 حرفاً، الكلمة أول ٣٠)
- description (150-160)
- cluster (calendar / universities / …)
- publishedAt + updatedAt
- author (اسم شخصي — لا "فريق مقالات" للـYMYL)
- authorRole (مثلاً: "استشاري مالي — CFA")
- reviewedBy (لمقالات صحية: اسم طبيب مراجع)
- tags (٥-٨، طويلة الذيل)
- faq (٥-٧)
- sources (قائمة روابط رسمية، ستُظهر أسفل المقال)

Body:
1. Hook — مفارقة/سؤال/رقم صادم (لا "يحتاج المستخدم")
2. [الأداة التفاعلية إن وُجدت]
3. جدول مقارنة/تصنيف (Google يعشقه لـFeatured Snippet)
4. أقسام H2 = أسئلة القارئ الفعلية (٥-٨)
5. قسم "أخطاء شائعة" أو "استثناءات" (يضيف عمقاً)
6. FAQ (٥-٧ أسئلة، جواب ٢-٤ جُمَل)
7. مصادر رسمية (قائمة قابلة للنقر)
8. "اقرأ أيضاً" — ٣-٥ روابط داخلية للأخوات + الهَب
```

## 5) قواعد المصادر (YMYL)

| الفئة | استخدم | تجنّب |

**قاعدة الاستشهاد**: كل رقم/تاريخ/ادعاء قانوني يحصل على استشهاد inline بجوار الجملة — لا في قائمة أسفل فقط. ونستخدم صيغة:

> ...يحلّ الحول بعد ٣٥٤ يوماً هجرياً ([هيئة الزكاة والدخل](https://zatca.gov.sa)).

## 6) الكاتب — أهم ثغرة نمﻷها فوراً

**الآن**: كل مقالاتنا تُوقَّع "فريق مقالات" — قاتل E-E-A-T لـYMYL.

**الحل المرحلي:**
1. **Persona حقيقية بمؤهّلات موثّقة**: كل عنقود يُدار من كاتب واحد بخبرة موثوقة (مالي/ديني/طبي/جامعي).
2. **صفحة كاتب `/author/[slug]`** لكل كاتب: بيو + خبرة + شهادات + رابط LinkedIn حقيقي.
3. **Person schema** في JSON-LD لكل مقال، تربط بصفحة الكاتب.
4. **"Reviewed by"** للمقالات الطبية: طبيب مرخّص + رابط سجّله (SCFHS للسعودية).

**إن لم يتوفر كاتب فعلي بعد**: استخدم اسم المؤسس/المالك مع تخصّصه الحقيقي (مثلاً: "أحمد الحربي — مطوّر ومحلّل SEO") — أفضل من "فريق مقالات". Google يفحص مؤهّلاتك عبر LinkedIn/وسائل التواصل.

## 7) عملية الكتابة (7 خطوات لكل مقال)

1. **قصد البحث**: ابحث الكلمة في Google، حلّل أول ١٠ نتائج، حدّد ما ينقصهم
2. **البريف**: املأ قالب seo-content-brief (كلمات، نية، جمهور، عدد كلمات، عناوين H2/H3)
3. **المصادر**: اجمع ٥-٨ روابط رسمية قبل الكتابة (لا تكتب ثم تبحث)
4. **الكتابة**: اتّبع البنية الإلزامية. مبني للمجهول ≤ ١٢٪. ٦ إشارات بشرية على الأقل (رأي/خلاف/تفصيل شخصي/عدم دقة)
5. **التحرير**: أعِد قراءة كل جملة، احذف الحشو، وحّد الأسلوب، تحقّق من كل رقم مع مصدر
6. **Schema**: أضف Article + FAQPage + HowTo (للأدوات) + Person (للكاتب) + BreadcrumbList
7. **الربط الداخلي**: ٥-٨ روابط لمقالات أخوات + الهَب + الفهرس. اربط المقال من ٢-٣ مقالات موجودة

## 8) قواعد التنسيق (الجهازين — RTL)

- فقرات ٢-٤ جُمَل (لا "جدار نص")
- H2 كل ٢٠٠-٣٠٠ كلمة
- جدول واحد على الأقل (Google يعشق الجداول للـSnippet)
- FAQ في نهاية المقال (لا قسم منفصل قبل الخلاصة)
- روابط داخلية inline لا في قسم منفصل فقط
- **em-dash عربي** `—` لا `-` للفواصل القاطعة
- **بولد** للمصطلحات المفتاحية أول ظهور فقط
- **`>` blockquote** للاقتباس الرسمي أو الجملة المحورية

## 9) ما يحوّل مقالاً عادياً إلى مرجعي

هذه هي بصمة Maqalat — بها نتفوّق على سطور/موضوع/الطبي:

1. **زاوية غائبة عن المنافس** — قسم أو جدول لم يذكره أحد قبلنا (مثلاً: "استثناء نهاية الأسبوع" في مقال الرواتب — لم أرَه في أي منافس)
2. **أداة تفاعلية** — Zakat/BMI/Pregnancy Calculator يفوز على أي نص ثابت
3. **جدول مقارنة رقمي** — "قياس vs التحصيلي vs المعرفية" جدول ٩ صفوف = Featured Snippet جاهز
4. **تحذير سلامة حقيقي** — YMYL طبي بلا تحذير = مؤشر منخفض الجودة
5. **مصدر رسمي مذكور بالاسم في المتن** — لا في القدم فقط
6. **اعتراف بالحدود** — "هذا الجدول تقريبي — للحالة الفعلية راجع…" = ثقة قوية
7. **تصحيح خطأ شائع** — "خلافاً لما يشاع، الأشهر الهجرية ليست ٣٠ يوماً دائماً" = تعلّم القارئ شيئاً

## 10) قائمة التدقيق قبل النشر (لا تنشر بدونها)

- [ ] الكاتب اسم شخصي بمؤهّل مذكور (ليس "فريق مقالات" في YMYL)
- [ ] Person schema مربوط بصفحة كاتب
- [ ] كل رقم/ادعاء قانوني بمصدر inline
- [ ] لا Mayo Clinic (استبدل بHarvard Nutrition Source)
- [ ] المبني للمجهول ≤ ١٢٪
- [ ] ≥٦ إشارات بشرية (رأي/خلاف/تفصيل/تحفّظ)
- [ ] جدول واحد على الأقل
- [ ] FAQ ٥-٧ أسئلة + FAQPage schema
- [ ] ٥-٨ روابط داخلية inline
- [ ] Article + BreadcrumbList schema
- [ ] عنوان ≤ ٦٠ حرفاً + الكلمة أول ٣٠
- [ ] Description 150-160 حرفاً
- [ ] Slug إنجليزي قصير + الكلمة
- [ ] تاريخ نشر + آخر تحديث
- [ ] لا كلمة "خلاصة/تلخيصاً/في الختام" (AI tell)
- [ ] لا "يحتاج المستخدم إلى" (AI opening)
- [ ] لا ادّعاء بلا مصدر
