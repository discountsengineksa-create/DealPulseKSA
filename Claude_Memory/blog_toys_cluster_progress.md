## القسم القادم: الهواتف والإكسسوارات

المستخدم أرسل شاشة AliExpress للهواتف — نفس المنهج ٣ مقالات لكل قسم فرعي:

### الأقسام الفرعية المرئية (٢٠+):
1. الهواتف المحمولة نفسها
2. الشحن والطاقة (شواحن، بنوك طاقة، كابلات، محوّلات، مبرّدات)
3. ملحقات SIM
4. ملحقات التصوير (فلاش سيلفي، عدسات، مرشحات، عصي سيلفي، حوامل ثلاثية)
5. حافظات الهاتف: **واقية، وظيفية، الموضة والديكور، محافظ وحاملات بطاقات، أحزمة الذراع، حافظات مزخرفة، حافظات مخصّصة**
6. واقيات الشاشة
7. مبرّدات الهاتف
8. أدوات النقر التلقائي
9. معزّزات الإشارة
10. مكبّرات الشاشة
11. تعليقات وأشرطة وسدّادات

### الاقتراح:
- بادئة `phone-accessories-` أو `mobile-` للعنقود
- ~٧٠-٩٠ مقال حسب دقّة تقسيم الأقسام الفرعية
- متاجر مقترحة: نون، بيتي شوب، AliExpress + إضافات (STC/Mobily لباقات)
