User decided (2026-05-29) to demolish the six analysis pages (تحليل المتاجر / الأقسام / بحث الأكواد / طلبات الأكواد / المستخدمين / الموقع) and rebuild them from scratch, correctly and with creative/innovative output.

**Why:** Analysis is the *strategic centerpiece* of DealPulse, serving 3 launch trajectories:
1. Operate it himself and **share data/intelligence with brands/companies**.
2. Possibly **sell the platform to companies** — who will run due diligence and reject any mess or fake/inflated data.
3. Wants companies to be **"shocked" (ينصدمون) by the final output** — wow-factor, enterprise-grade.

**Hard constraint:** ZERO fakery (بعيد عن التزييف). No vanity metrics, no features that pretend to work (e.g. the current proxy/datacenter filter that excludes 0, the WoW% on 3-event samples, contradictory web numbers across pages). Numbers must survive an acquirer sample-checking them.

**How to apply:** Every analytics decision should favor: provenance/data-trust badges, sample-size gates, confidence ranges over false precision, one source-of-truth metrics layer, "decision-not-data" (each module = one question + one action), and enterprise frameworks acquirers recognize (cohort retention, RFM, real funnel, anonymized peer benchmarks, forecasting, anomaly alerts). Build for two audiences: brand-facing dashboards AND platform-level investor KPIs. See [[store_analytics_bi]] for the prior rebuild of تحليل المتاجر.
