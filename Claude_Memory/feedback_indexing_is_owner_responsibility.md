**القاعدة:** مهمّتي = الكتابة الصحيحة الدقيقة المطلوبة + الدفع. الفهرسة (Google Indexing API، الحصّة اليومية ٢٠٠، توقيت الـping، أي URLs تُدفع) **مسؤولية المالك**، ليس شغلي.

**Why:** المالك قال صراحة ٢٠٢٦-٠٩-١٢ بعد ما دفعت ٣ URLs بلا طلب مباشر: «مالك شغل في الحصّة اليوميّة، عليك بالكتابة الصحيحة والدقيقة والمطلوبة منك ودفعها. الفهرسة أنا مسؤول منها.» الرسالة أوضح ما تكون: التقسيم في التخصّص — أنا للمحتوى/الكود، هو للـSEO التشغيلي.

**How to apply:**
- **لا** أشغّل `npm run index:ping` أو `node scripts/ping_google_indexing.mjs` تلقائياً بعد أي تعديل، حتى لو منطقياً «الوقت مناسب».
- **لا** أقترح تشغيل الفهرسة كخطوة تالية في نهاية ردودي («هل أدفع لـGoogle الآن؟»).
- **لا** أحسب حصّة الفهرسة في تخطيطي («يبقى ١٩٧ URL»، «الحصّة تكفي لكذا»).
- **نعم** أعدّل السكربتات لو طُلب مني (كتحسين قبول CLI args).
- **نعم** أُخبر المالك أن تعديل ميتا لن يظهر في SERP قبل إعادة الزحف — كمعلومة، لا كدعوة للتصرّف.
- الاستثناء الوحيد: لو طلب المالك صراحةً «شغّل الفهرسة الآن» أو «ادفع هذه الـURLs».

**التطبيق النموذجي:**
- سيء: «سأعدّل الميتا ثم أدفع ٣ URLs لـGoogle Indexing.»
- جيد: «سأعدّل الميتا وأدفع الكوميت. جوجل سيرى التغييرات عند إعادة الزحف — الفهرسة قرارك.»
