**العنقود (web 0746124):** ١٢ مقالاً بادئة `asq-`: الهَب + مسك عبدالصمد + خلطة القرشي + دهن العود + تبر/معمول + البخور + الزيوت العطرية + رجالي + نسائي + فيفا/سفاري/ستار + مسك الجسم والعناية + الهدايا.

**قرار التموضع:** بُني على **خطوط المنتج الفعلية من المتجر** (مأخوذة من قوائم الموقع: العطور/الزيوت العطرية/العود والبخور/منتجات العناية/المجموعات/عروض خاصة) لا على تعليم عام عن العود — لأن عنقود `oud-*` العام وعنقود `oudroyal-*` يغطّيان التعليم أصلاً، والتكرار يُضعف الاثنين. الربط بينهما تكاملي لا تنافسي.
